# Modular-Peripheral-Quick-Dock-Hardware-Prototype-

A 3D-printed, low-profile docking cradle engineered to streamline high-bandwidth peripheral and display connections between mobile CAD setups and external desktop displays.

## Overview & Architecture
- **Function:** Magnetic-guided modular alignment for display routing (HDMI/Type-C) and USB peripherals.
- **Form Factor:** Angled passive-airflow cradle with integrated cable strain relief.
- **Tolerances:** Critical port engagement tolerances held within $\pm 0.2\,\text{mm}$.

## Build Specifications
| Parameter | Value |
| :--- | :--- |
| **Material** | PLA / PETG |
| **Print Process** | FDM (0.2 mm layer height, 20% gyroid infill) |
| **Alignment** | Recessed guide rails + dual N52 neodymium locators |
| **Cooling** | Passive convection vents along underside chassis |

## Iteration & Verification
1. **v1.0:** Baseline geometric fit; identified cord fatigue and loose connector mating.
2. **v1.5:** Adjusted clearance around connector housings; added $2.5\,\text{mm}$ fillet relief.
3. **v2.0:** Integrated magnetic indexing and base ballast to enable single-handed docking/undocking.
